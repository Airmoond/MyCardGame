# 卡牌游戏

这是一个以 C++ 编写的卡牌战斗逻辑原型仓库。

当前仓库主要包含三部分：

- `游戏基础框架/battle.*`
  战斗核心，负责回合推进、状态变化和规则结算。
- `游戏基础框架/battle_bridge.*`
  面向表现层的桥接接口，适合作为 Godot、GDExtension 或其他前端的接入边界。
- `游戏基础框架/main.cpp`
  控制台演示前端，用来快速查看战斗逻辑是否正常工作。

## 当前特点

- 战斗逻辑和表现层已经基本解耦。
- 支持读取战斗快照 `getSnapshot()`。
- 支持读取战斗事件 `consumeEvents()`。
- 支持按卡牌实例 ID 出牌，方便表现层稳定追踪卡牌对象。
- 支持逐步推进 `advanceOneStep()`，也支持直接推进到下一个决策点。

## 推荐阅读顺序

1. `游戏基础框架/battle_types.h`
   先看基础数据结构和枚举。
2. `游戏基础框架/battle.h`
   再看战斗核心对外提供了哪些接口。
3. `游戏基础框架/battle.cpp`
   结合实现理解回合推进和动作结算流程。
4. `游戏基础框架/battle_bridge.h`
   如果你准备接 Godot，优先看这里。
5. `GODOT_INTEGRATION.md`
   这里总结了推荐的 Godot 接入方式。

## 目前适合做什么

这套代码已经适合继续向 Godot 表现层开发推进，尤其适合先做：

- 战斗界面原型
- 手牌展示与点击出牌
- 敌人意图展示
- 基于事件流的简单动画

如果后续要做更复杂的演出、更多卡牌机制和正式内容配置，建议继续扩展事件语义和内容数据层。
